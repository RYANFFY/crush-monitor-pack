# Crush 好感监控器 · Windows 安装包

> 这是**第三方打包**的 Windows 安装程序。源码与版权属于原作者 **[FerryCorleone/crush-monitor](https://github.com/FerryCorleone/crush-monitor)**，本仓库只提供打包好的安装包，方便不想折腾命令行的人一键装上。

## ⚠️ 安全公告：旧版卸载程序可能误删整个目录，请先读这一节

**受影响版本：`v1.1.1-win.1` 及更早的 Windows 安装包。**

这些版本的卸载程序会把「安装目录」当成软件自己的目录**整棵递归删除**（`rmdir /s /q`），而不是只删自己装进去的文件。如果当时把程序装到了**盘符根目录**（例如 `D:\`），卸载的删除范围就会覆盖整个盘，表现为「盘被清空」。装到一个已经放着其他资料的普通文件夹，同样会误删那个文件夹里的非程序文件。

### 已经装过旧版，现在该怎么做

1. **不要运行旧的卸载程序** —— 包括安装目录里的 `卸载.cmd`，以及 Windows「设置 → 应用」里的卸载入口（两者调用的是同一个脚本）。
2. **不要为了升级到修复版而先卸载旧版。** 直接运行修复版安装包覆盖安装即可；修复版会把程序装进独立的 `CrushMonitor` 子目录，并写一份安装清单。
3. 想彻底清掉旧版，请**手动逐个删除**下面这些具体目标，不要删除整个盘或整个上层目录：
   - 桌面和开始菜单里的「Crush 好感监控器」快捷方式
   - 旧安装目录里的 `好感度监测器.exe`、`node.exe`、`app\`、`dist\`、`Microsoft.Web.WebView2.*.dll`、`WebView2Loader.dll`、`app.ico`、`说明.txt`、`stop.ps1`、`停止.cmd`、`uninstall.ps1`、`卸载.cmd`
   - 注册表项 `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Uninstall\CrushMonitor`
4. **如果旧版当初装在了盘符根目录**，请不要对该盘做任何递归删除操作（`rmdir /s`、`del /s`、`Remove-Item -Recurse` 等），逐个确认后再删。

### 修复版（v1.1.2 及以后）怎么保证安全

- 安装位置规范化后**拒绝盘符根目录和系统目录**，并始终装进独立的 `CrushMonitor` 子目录
- 目标文件夹已存在且不属于本程序时**拒绝写入**，避免误伤
- 安装完成后写一份文件清单（`.crushmonitor-manifest.txt`）；卸载**只按清单删文件**，并且每个路径都要校验确实位于安装目录内
- 你自己放进去的文件、`.env`、聊天记录都不在清单里，**一律保留**
- 最后只删除空目录，**不再有任何递归删除**；目录里没有清单时，卸载直接拒绝执行

相关讨论见 [issue #1](https://github.com/RYANFFY/crush-monitor-pack/issues/1)。

## 这是什么

上游项目是一个用 Jev 模型分析聊天记录的小工具：逐句标出情绪与意图、给出好感信号评分、给自己的回复按 SSS–D 分档，并建议下一步怎么聊。它原本需要在终端里依次执行 `npm ci`、`npm run setup`、`npm run build`、`npm start` 才能跑起来，这个仓库把整套东西打成了一个双击就能装的安装包。

## 与上游的差别（只在打包层）

- **单文件安装包**：可选安装位置、带进度条、自动创建桌面和开始菜单快捷方式；装完这个安装包就能删掉
- **卸载安全**：装进独立的 `CrushMonitor` 子目录，按安装清单删除程序文件，用户数据和新增文件一律保留（详见上面的安全公告）
- **独立应用窗口**：原生窗口 + WebView2 渲染，不需要命令行，也不再是浏览器标签页
- **首次运行向导**：选平台（TypeSafe / Vercel AI Gateway / OpenRouter）→ 粘贴自己的 API Key → 真机验证后即可使用
- **端口自动选择**：默认 3178，被占用会自动换；聊天记录保存在程序目录里，绿色版可整体搬走
- **多了一个「导出结果」按钮**：可把聊天原文与全部分析结论导出成一份 HTML 报告
- 上游代码逻辑未做修改；**安装包里不含任何 API Key**，Key 由使用者在首次运行时自己填写

## 使用步骤

1. 下载并双击安装程序。若出现「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」（未签名程序的常规提示）
2. 选择一个安装位置 → 安装 → 程序自动打开（实际会装在你选的位置下的 `CrushMonitor` 文件夹里）
3. 第一次打开会让你选平台并粘贴自己的 API Key

Key 需要自己准备：TypeSafe 目前是邀请／候补制，也可以用 OpenRouter 或 Vercel AI Gateway 的 Jev 接入。费用、额度与隐私以自己的账号和所选平台为准。
